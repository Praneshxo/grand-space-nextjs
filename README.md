# Grand Space Interiors — Next.js

Premium interior design website built with Next.js 14 + GSAP.

## Setup

```bash
cd grand-space-nextjs
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Features
- Working hamburger menu with full-screen overlay
- GSAP ScrollTrigger fade-up animations
- Animated stats counters
- Three-card section (Kitchens / Interior Design / Materials)
- All original GS Interiors content (about, services, stats, contact)
- Responsive design
- Inspired by Cashmere, Merise, Espacio, Strakk, and Aristo aesthetics

Replace Unsplash image URLs with your own project photos when ready.
